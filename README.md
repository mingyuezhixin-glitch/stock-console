# 投资控制台 · GitHub Pages 部署说明

四档金字塔加仓 · 买点区排序 · 持仓档位联动提醒

---

## 一、这个包是什么

一个**纯静态**的美股操作台，不需要服务器、不需要数据库、不需要安装任何东西。

| 文件 | 作用 |
|---|---|
| `index.html` | 主程序（153 KB，CSS/JS 全部内联，零外部依赖） |
| `manifest.webmanifest` | 让手机能「添加到主屏」，像 App 一样打开 |
| `sw.js` | Service Worker，断网也能打开界面看上次的持仓 |
| `apple-touch-icon.png` | iPhone 主屏图标（180×180） |
| `icon-192.png` / `icon-512.png` | 安卓 / PWA 图标 |
| `favicon-32.png` | 浏览器标签页小图标 |

**技术说明**：行情来自腾讯 `qt.gtimg.cn`（该接口开放跨域），持仓和设置存在你自己浏览器的 localStorage 里，不经过任何第三方服务器。

## 二、部署（三步，约 3 分钟）

### 第 1 步：建仓库

1. 打开 https://github.com/new
2. **Repository name** 填 `stock-console`（也可以起别的名字，英文小写）
3. 选 **Public**（Private 仓库用 GitHub Pages 需要付费）
4. 点 **Create repository**

### 第 2 步：上传 7 个文件

1. 在新仓库页面点 **uploading an existing file**（或直接访问 `https://github.com/你的用户名/stock-console/upload/main`）
2. 把 `gh-pages-deploy` 文件夹里的**所有文件**拖进去
   - ⚠️ 只拖这 7 个：`index.html`、`manifest.webmanifest`、`sw.js`、`apple-touch-icon.png`、`icon-192.png`、`icon-512.png`、`favicon-32.png`
   - ⚠️ 不要拖 `_make_icons.py`（那是生成图标用的脚本）
   - ⚠️ 不要建子文件夹，全部平铺在根目录
3. 下方 **Commit changes** 点一下

### 第 3 步：开启 Pages

1. 进仓库 → **Settings**（顶部标签）
2. 左侧栏找 **Pages**
3. **Source** 选 `Deploy from a branch`
4. **Branch** 选 `main`，目录保持 `/ (root)`
5. 点 **Save**
6. 等 1-2 分钟，页面顶部会出现绿色提示，地址是：

```
https://你的用户名.github.io/stock-console/
```

例如你的账号是 `mingyuezhixin-glitch`，那就是：

```
https://mingyuezhixin-glitch.github.io/stock-console/
```

## 三、手机使用

### 安卓 / 微信内置浏览器

直接用上面那个网址打开即可。

### iPhone 加到主屏（推荐）

1. **必须用 Safari 打开**（微信里打开后，点右上角「…」→「在 Safari 中打开」）
2. 点底部 **分享** 按钮
3. 往下找 **添加到主屏幕**
4. 名称可以改成「操作台」→ 点 **添加**

之后从主屏点开，就是全屏无地址栏的 App 样子，图标是深色底 + 四根蓝色柱子。

### 电脑

浏览器打开同一个网址，收藏即可。

## 四、重要：两种模式的区别

这个页面会**自动检测**有没有连上你电脑上的 Python 服务：

| 功能 | 连了电脑服务 | 纯网页（GitHub Pages） |
|---|---|---|
| 实时行情 / 52周高低 | ✅ | ✅ |
| 回撤 / 买点区 / 四档价位 | ✅ | ✅ |
| 持仓记录 / 档位联动提醒 | ✅ | ✅ |
| 账户资金 / 检查清单 / 排序 | ✅ | ✅ |
| **手机电脑数据同步** | ✅ | ❌ 各存各的 |
| 均价 / MA20 / MA60 / 波动率 | ✅ | ❌ |
| AI 解读 | ✅ | ❌ |

**怎么分辨当前是哪种模式**：看左上角状态文字

- `已连接` → 连上了电脑上的服务，功能全
- `离线·腾讯直连` → 纯网页模式，靠浏览器直连行情

## 五、三个必须知道的限制

### 1. 数据存在浏览器里，不在云端

持仓、资金、自选股都存**你当前这台设备、这个浏览器**的 localStorage。

- 手机上加的持仓，电脑上看不到
- **清除浏览器数据 / 清除网站数据 → 持仓全丢**
- 换手机、换浏览器 → 数据不跟过去

**建议**：定期在「持仓」页用「批量导入」那套格式，把持仓记一份到备忘录里做备份。

### 2. 没有均价和 AI 解读

这两个功能依赖电脑上的 Python 服务：

- 均价/MA 要调 Nasdaq 历史接口，那个接口要求伪造 `Origin: nasdaq.com`，**浏览器不允许伪造**，只有后端能做
- AI 解读要调大模型，需要 API Key，也不适合放在公开网页里

### 3. 首次打开要等一下

行情要走真实网络请求，首次加载大约 2-4 秒。如果显示「离线·行情失败」：

- 检查手机有没有正常联网
- 某些安全浏览器会拦跨域请求，换 Safari / Chrome 试
- 等 30 秒点右上角「刷新」重试

## 六、更新代码怎么办

以后你在电脑上改了 `股票操作台.html`，需要重新生成部署包再上传：

1. 用 `_make_icons.py` 同目录的思路重新生成 `index.html`（把主文件的 `<head>` 加上 PWA meta、`</body>` 前加上 SW 注册代码）
2. 覆盖仓库里的 `index.html`
3. **重要**：打开 `sw.js`，把第一行的 `stock-console-v1` 改成 `stock-console-v2`
   （不换版本号，手机会一直用旧缓存）
4. 上传覆盖，等 1 分钟

手机上需要**完全关掉页面再打开**才能拿到新版。

## 七、隐私说明

- 仓库是 Public，但**代码里没有任何你的个人信息**——持仓和资金都存在你自己浏览器里，不在仓库里
- 行情请求直接发往腾讯，不经过任何中间服务器
- 如果不想公开代码：GitHub Pages 免费版只能配 Public 仓库；想私有的话可以用 Cloudflare Pages（支持私有仓库，也免费）

---

## 八、备选方案

如果 GitHub 访问不稳定，同样的这 7 个文件也可以直接传到：

| 平台 | 说明 |
|---|---|
| **Cloudflare Pages** | 支持私有仓库，国内访问通常比 GitHub 快 |
| **Vercel** | 拖拽上传即可，免费 |
| **Netlify** | 拖拽上传即可，免费 |
| **腾讯云 / 阿里云 OSS** | 对象存储开静态网站托管，需备案域名 |

因为这 7 个文件是纯静态的，**任何静态托管都能用**，代码一行都不用改。
